# 可复用的 insight（Dong 的笔记，不在站点上展示）

## 2026-10-14 · 来自 Anthropic Scion
1. **用户变了，就重审设计前提**：Git 为「人、偶尔离线、每天提交几次」设计；换成一直在线、每天几万次提交的智能体，前提失效。给智能体用的系统都值得把隐含前提列出来逐条重问。
2. **把「存什么」和「怎么看」分开**：内容按哈希存一份，快照只是一份索引。数据湖、Docker 镜像分层、文档版本管理同理：不可变内容可随意缓存、去重、共享。
3. **贵的计算在中心算一次，大家共用**：blame 等派生数据在服务端预算并增量更新；推荐系统特征库、知识库 embedding 同理。
4. **按需取，层层缓存**：不拉全量，要什么取什么，加多级缓存；内容寻址让命中率做到 99% 以上。
5. **把「事前严防」换成「事后快修」**：先合入、出问题快速定位/回滚/让 Claude 修；前提是定位和回滚足够便宜。
6. **人的角色从逐行审改为把方向**：评审看意图、对 Claude 说「不」。
