第 01 节

个人 Agent 与记忆/上下文管理

Reglos：用户级记忆在线演化 + harness 离线 RSI，且用 held-out 防刷榜

Reglos.ai · arXiv 2026-11-05 前后 · 原文 约 30–45 分钟（论文）

问题。 论文个人 Agent 要跨月追踪偏好变更与「请忘记」；记忆常被正确写入，却在读入上下文的 harness上翻车。作者开发数据里约 31% 失败是证据已在上下文、读者仍选错；仅对「触发该补丁的失败」打分，很容易过拟合。

怎么做的 / 证据。 论文内环：每用户 append-only 事实（带有效期与遗忘墓碑），夜间 Dream 重写 profile。外环：Claude Code（Opus 5.5）从失败轨迹提 harness 补丁，Codex（GPT-6.1 Sol）跨模型家族当 critic 拒刷榜，冻结后再用固定评估器 + 第二读者（GPT-5.6 Luna）在 persona 不相交的验证半集上验收。同一骨干写记忆：Qwen3.8-27B 作答时 PersonaMem-v2 61.3%、LongMemEval-S 84.0%，相对 Mem0 / MemOS / EverOS 领先；GPT-5.6 Luna 作答时 57.5% / 87.2%。外环把验证准确率从 54.2→60.7（约 +6.5 ppt）。敏感信息题约 91.4%，遗忘题约 63.1%。

评论与昨日 Meta²「run 内进化、跑完即弃」互补：Reglos 把个人记忆状态与共享 harness 代码拆成两套时间尺度，并用跨家族 critic + held-out 约束「coding agent 改 harness」。适合对照做个人 Agent 记忆产品。

是否值得读原文 · 做个人记忆 / harness RSI 必读 Method + Table 1，约 20 分钟。

Reglos: A Self-Evolving Personal Memory Agent with Recursive Self-Improvement (arxiv.org) reglos.ai (reglos.ai)

第 02 节

RSI（自我迭代 / 人参与的迭代）

METR：Anthropic 能力增速约 2×，多数或来自「用 AI 做 AI R&D」

METR · 2026-11-05 · 原文 约 25–40 分钟（长报告摘要）

发生了什么。 第三方/独立评估8/12–10/29 在 Anthropic 做高权限评估（内部基准、训练算力、访谈等）。主观结论（高不确定）：截至 2026-10，Anthropic 在 well-specified 任务上的能力增速约为 2024-03–2025-10 的 约 2×（METR 称不排除真值约 1.3–3×）。经验发现：自 2025-10 起内部 AECI 增速约 1.9×〔95% CI 1.5–2.8×〕，约等于过去一年走过此前约两年进度；可排除「训练算力缩放加速」解释。访谈/自报 uplift 与「AI 贡献占当前加速的多数（编者读作约 ≈80% 猜测）」一致，但仍有显著非 AI 因素；R&D 加速目前主要是辅助而非全自主，但有「signs of life」。未看到未来 12 个月明确瓶颈——故存在进一步复合加速的风险；大量关键证据被 Anthropic 以「防其他开发者加速」为由涂黑，公众更依赖 METR 判断。

评论这是本周 RSI 叙事的「实证锚」：不是玩具 harness 榜，而是 lab 内能力斜率。阅读时务必带上局限——只谈 well-specified、涂黑证据、以及「加速≠已跨越灾难阈值阈值」。Nathan Lambert 提醒：缺好基准本身也可能是 RSI 瓶颈（见第 8 节）。

是否值得读原文 · 关心 RSI / 治理必读 Executive summary + Key findings，约 15 分钟。

Recursa：无更强教师，靠知识库 bootstrap + 多 learner RSI 抬域内任务

Alibaba Research · arXiv · 原文 约 30–40 分钟

问题。 论文新域往往没有大量专家标注与可靠奖励；能否让同一骨干既当 solver 又当 learner，只改 instructions / skills / memory 知识库，而不改权重、也不请更强教师？

怎么做的 / 证据。 论文先对语料 bootstrap（导航技能 + 自生成练习），再在训练任务上做多 learner 分解—合并—反思。Harvey LAB Firm Knowledge：DeepSeek-V4.1-Flash held-out all-pass 30.0→55.0%；Qwen3.8-Flash 35.0→46.0%。多 learner 明显强于单 learner；bootstrap 本身更省 token/轮次，准确率抬升有限。Harness 侧强调 REPL 工具组合 + 可编程上下文 + 子代理编排。

评论与 Meta² / Reglos 同属「冻权重、改外围」RSI，但目标是域知识库而非通用 coding harness。适合法律/金融等「材料多、判据局部」场景。

是否值得读原文 · 做域内 Agent / 知识库 RSI 值得，先 Abstract + §6 表，约 20 分钟。

Recursa: Toward Recursively Self-Improving Foundation Model Systems (arxiv.org) @omarsar0 (x.com)

第 06 节

高效使用 AI / Agent

从今日材料抽出的三条可执行提示

1. 个人记忆：分「用户状态」与「共享 harness」两环。 论文见 Reglos：用户事实用 append-only + 遗忘墓碑在线改；改召回/策略代码放到离线 RSI，并用跨模型 critic + held-out 验收。自建 Agent 可先度量「证据已在上下文仍答错」占比，再决定是改写记忆还是改 harness。

2. 域适应：先 bootstrap 地图，再多 learner 修行为。 论文见 Recursa：语料导航技能先降搜索成本，真正抬 all-pass 靠任务经验上的分解—合并；单 learner 容易原地打转。做垂直 Agent 时，把「材料地图」与「失败聚类后的技能补丁」拆开排期。

3. 读 RSI 新闻时分清斜率与阈值。 第三方METR：约 2× 加速 ≠ 已越过灾难性自动化 R&D 阈值；且证据大量涂黑。产品侧选模型时，继续把 Time-per-Task / effort（昨日 AA）与今日 Inkling 的 variable effort 当成一等公民——同一模型不同 effort 成本差可达数倍。
