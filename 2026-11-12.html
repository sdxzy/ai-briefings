第 01 节

个人 Agent 与记忆/上下文管理

两条：一条测「harness 记忆到底有没有用」，一条是新开源的本地个人 agent。

Continual-ARC：同一类题隔一阵再出现，三个流行 harness 基本没记住；训练 9B 模型的权重反而能泛化到新题

Unify · arXiv · 2026-11 · 原文 论文约 40 分钟（正文 §2–§4 约 15 分钟）

问题。 论文常驻 agent 的卖点是「越用越懂你」。但现有基准多半每道题只出一次，分不清 agent 是记住了答案还是学会了方法。作者想测两件事：上个月做过的同类题，这次能不能更省力（记忆）；没见过的新题，会不会因为经验而做得更好（泛化）。

方法。 论文从 ARC-AGI 题库做一条 200 题实例的「工作流」：25 个任务交替出现，每次都换新输入（不能缓存答案），中间有长短不一的空档，新任务不断加入。每个实例可以花钱要示范或提交答案，答错扣分，没解出扣满预算。流结束后冻结系统，用已见任务的新实例测记忆，用 100 道没见过的评测题测泛化。记忆型（笔记、技能文件）和权重型（训练 LoRA）用同一把尺子比。

证据。 论文

  • prime-agent 搭 Qwen3.5-9B，开着持久化与清空状态几乎没差别（已见题节省 −0.01）；多数 harness 方法甚至不如一个只缓存示范的简单基线。
  • 用 GPT-6 Luna 跑 prime-agent、hermes-agent、openclaw：照出厂设置都没测出可度量的节省；每次判分后提示「多存点」，只有 prime-agent 有效（0.42），hermes-agent 0.18、openclaw 0.07 都在噪声内。
  • 给「专家指导」（为每个任务写 Python 程序、用示范验证、存下来复用）后，已见题节省升到 0.62–0.74，说明 harness 本身做得到，缺的是「该存什么」的判断。
  • 一个具体原因：GLM 其实为每个任务都存了文字规则，但 prime-agent 每个实例只展示 6 条记忆，且在知道是哪道题之前就选好，154 次重遇里只有 40 次拿到了对应规则。
  • 所有 harness 方法在新题上都没有收益；用 DAgger 训练 Qwen3.5-9B 的 LoRA 后，新题节省 0.29、已见题 0.57，多用户（2 人）时新题升到 0.40。

局限。 只在最简单的 ARC-AGI-1 轨道上做了主实验，模型偏小；ARC 是抽象谜题，结论能否迁移到办公、编码等有大量先验知识的领域，作者自己也说未知。作者所在公司做 agent 系统，论文已披露。

短评。 评论「记忆检索在任务识别之前就选好」这个失败点很具体，值得自查：记忆若不按当前任务检索，存得再多也用不上。

是否值得读原文 · 值得。读 §4「Harnesses as shipped」和附录 E（逐个 harness 存了什么），约 20 分钟。

n8n 开源个人 agent Nod：本地沙箱电脑 + 浏览器，动手前先问，模型自选

n8n Labs · 2026-11-10 · 原文 约 5 分钟

是什么。 官方n8n Labs 发布的研究预览版，独立于 n8n 本体，Mac / Windows 桌面应用，开源。它在本机跑一个沙箱「电脑」和浏览器，可以在已连接的 Gmail、日历、Drive、Slack 里办事，也能操作没有集成的网站；例子包括取消订阅并拒掉挽留优惠、每月登录供应商门户下载发票、从无法导出的看板里抄数据进周报。有后果的动作前先征求同意。

记忆与主动性。 官方官方称它记得数月对话，会读已连接的应用并主动提出可以代办的事；可在 App、Telegram 或 WhatsApp 里对话，后台并行跑多个任务，重复任务可定时。

局限。 研究预览，长期记忆效果只有官方自报；「主动提出代办」与权限边界如何把握，需要实际用过才知道。

第 02 节

RSI（自我迭代 / 人参与的迭代）

一篇讲「agent 自改时哪条经验能留下」，一篇讲「模型一代代训练下去，思维链还能不能监控」。

FGSE：把每条「经验教训」写成带前提条件的假设，先在临时状态里证伪，通过了才写进长期记忆

南洋理工 / 佐治亚理工 / 新国立等 · arXiv · 2026-11 · 原文 约 30 分钟（§3 诊断实验和 §6.3 消融最有用）

问题。 论文例如 agent 在某个订票网站学到「先点搜索再填日期」，直接写进记忆；下次在一个长得像、流程却不同的网站上照做就出错，还可能把原来会做的题做坏。作者的诊断实验显示：越宽泛、越没有适用条件的教训，造成的「边界伤害」和「旧题回退」越大，而且连续写入会累积错误。

方法。 论文每条候选更新写成结构化假设：前提条件、行为改变、预期效果、验证器。先只在临时状态里启用，跑三组探针：目标迁移（该帮上忙的新题）、证伪（看起来像但不该触发的题、诱饵题）、回归（以前做对的题）。增益够、证伪失败率低、回归损伤小才提交；增益够但失败集中在可分离的子范围时，收窄一次前提条件再测；否则拒绝。提交后若频繁违背预期效果，会被移出检索。

证据。 论文DeepSeek-V3.1 底座下 WebArena 39.8、AppWorld 平均 78.8、τ-Retail / τ-Airline Pass@1 0.724 / 0.487；证伪失败率 5.0%、回归损伤 1.3%、有害提交 3.6%。一轮里 380 个候选只提交 104 个；被拒的 101 个「增益达标」候选，证伪失败率 22.82%。去掉证伪探针后有害更新从 3.6% 升到 10.6%；把门控换成 LLM 评审，WebArena 掉 3.1 分。

局限。 只适用于有可执行验证器的环境，验证器本身要学或近似时会怎样没有展开；主表里不少基线是 GPT-4 / GPT-4o 时代、取自不同论文的数字，横向比较要打折扣。

短评。 评论方法不复杂，核心就是「给记忆写入加回归测试和反例测试」。和上周 TRUST 的统计门控、本周 Continual-ARC 的结论放在一起看：问题不只是存什么，还有凭什么留下。

OpenAI：更强的模型「不写思维链也能想」，思维链监控在变弱；四个来源分别出在预训练、架构、RL 和上一代生成的数据

OpenAI Alignment · 2026-11-10 · 原文 博客约 25 分钟

问题。 官方OpenAI 把「看思维链（CoT）发现模型不良意图」当作安全论证的一根支柱。GPT-6 Astra 上他们观察到：非对抗场景下 CoT 可监控性下降、对抗测试中更会规避监控、不用 CoT 也能完成的任务明显变多。

做法。 官方用两个代理指标：无 CoT 能力（一次前向、不写推理也能解题）和 CoT 可控性（被要求增删、改写推理内容时能否照做），沿训练流程逐段测。

四个发现。 官方

  • 预训练：无 CoT 能力随基座困惑度下降平滑上升，模型越强越不需要把想法写出来。
  • 架构：多数评测里只由困惑度决定，但在多跳计算类评测上，有些架构在同等困惑度下涨得更陡。
  • RL：即使只有长度约束和最终答案判分、没有过程监督，CoT 可控性也会在 RL 中上升；加工具监督后略再升。
  • 跨代：用模型生成的数据做 SFT，可控性会像「潜意识学习」一样传给下一代模型。

系统卡补充。 官方Astra 系统卡称，英国 AISI 的评估提示其无 CoT 时间跨度可能提升约一个数量级；OpenAI 目前没有开放 reasoning=None 的计划，并在研究激活监控等替代手段，但承认「不确定这些努力能否保住信心」。

局限。 两个指标都是「最坏情况规避能力」的代理，作者在附录里讨论了效度；没有给出能逆转趋势的训练方案。

短评。 评论第四点和 RSI 直接相关：用本代模型数据训练下一代，会把「更会控制推理文本」这类性质一并传下去，这是模型参与自身迭代时一个不显眼的副作用。

是否值得读原文 · 值得，做 agent 监控或安全评估的读四个发现和附录 A 的效度讨论。

第 03 节

各领域模型能力进展

AlphaGenome 2：同一段 DNA 在不同细胞里怎么被读，细到细胞类型和状态；致病变异召回近翻倍

Google DeepMind · 2026-11-11 · 原文 博客约 8 分钟

问题。 官方心脏、大脑、免疫细胞的 DNA 序列相同，一个碱基的变异却可能只在某类细胞里致病。上一代 AlphaGenome 用「组织平均」数据训练，说不清变异在哪种细胞里起作用；Nature 报道中有研究者直言这让它「对我们没那么有用」。

做法。 官方改成条件模型：输入百万碱基的 DNA 序列，加上目标条件（组织、细胞类型或状态），条件信息贯穿每一层；一次只预测一个条件。训练数据来自 68 种组织的 1 亿多个单细胞图谱。用户还可以上传几十个细胞的单细胞 RNA-seq 数据，压缩成细胞状态表示，让模型预测没见过的状态，无需重训。

证据。 官方在 28 种免疫细胞的 TenK10K 数据集上，因果变异识别 30% 对 16%，方向性基因效应 43% 对 23%（对比在单细胞数据上微调的初代 AlphaGenome 等工具）；复现了「远端调控开关变异只在肠道巨噬细胞里过度激活 ETS2、导致炎症性肠病」的已发表结论；在新冠 mRNA 疫苗数据上，区分出激活与静息 T 细胞，并发现一个重症相关变异只在激活状态下影响更大。第三方Nature 报道称训练覆盖 637 种人类和 311 种小鼠细胞类型。

局限。 非商业研究可通过 API 使用，商业研究为私有预览；预测仍需湿实验验证。

是否值得读原文 · 非生物方向看博客前半即可；「条件输入贯穿全网络 + 少量样本即时适配新状态」的做法有通用参考价值。

第 04 节

世界模型 / 具身

Runway 开源 Praxis-1：27B 世界动作模型同时预测下一段视频和动作，Apache 2.0，可商用

Runway · 2026-11-11 · 原文 博客约 4 分钟；README 约 10 分钟

是什么。 官方Praxis-1 是 Runway 9 月发布的首个世界动作模型，建立在其通用世界模型同一套大规模视频预训练之上：27B 参数的混合专家扩散 Transformer，每次调用同时预测下一段视频和下一段动作，机器人执行这段动作后再进入下一轮。今天连权重、推理与微调代码（含全量微调和 LoRA）一起以 Apache 2.0 开放，包括商用。

证据。 官方在 NVIDIA RoboLab-120 榜上 1,200 个回合成功率 46.2%，FLUX 3 Action 42.9%、Cosmos3 Nano 36.8%、π0.5 28.0%。发布伙伴已在双足人形、六轴工业臂和双臂仓储机器人上运行。提供单臂 DROID、双臂 YAM 两个检查点和一个不带动作头的基座检查点（用于新机型），以及 NVFP4 量化版；已进 LeRobot 与 vLLM-Omni。第三方Robotheca 依模型卡记录：动作专家约 0.3B，以 15 Hz 输出 24 步动作块。

局限。 榜单成绩为官方自报；NVFP4 路径的闭环精度官方 README 注明尚未确认；单检查点约 54 GB，门槛不低。

短评。 评论「视频生成预训练 → 机器人控制」这条路线今年 Cosmos、GR00T 都在走，Runway 选择完全开放权重，加上同日 Jim Fan 发 GR00T 2 1 倍速无剪辑完成化学实验，具身方向的开放基座正在变多。

是否值得读原文 · 做具身的读 README 的检查点与输入输出说明；其他读者看博客即可。

第 05 节

AIGC 视频生成

Intangible 2.0：每次生成底下都有一个真实 3D 场景，agent 从简报搭场景、摆相机、批量出镜头

Intangible · 原文 帮助文档首页约 5 分钟；Cooper 的幕后视频约 2 分钟

问题。 第三方纯生成式视频改一个镜头往往要整段重新抽卡，换机位后场景、道具、人物也对不上。

做法。 官方Intangible 的 Canvas 把一段文字简报交给 agent：写简报、生成参考图和 3D 模型、搭一个 3D 场景、为每个镜头放一台相机，再把镜头渲染成图和视频。所有镜头来自同一个场景，所以布景、产品和人物跨镜头一致；推镜、环绕、摇臂、跟拍是在 Compose 里给真实相机打关键帧，而不是写进提示词。可导入 FBX / OBJ / GLB、高斯泼溅，或从 Blender、Maya、Houdini、Unreal 带入场景，并给物体绑定实物照片作参考；每个镜头可以单独选图像 / 视频模型。改场景后重渲，而不是从头重写提示词。更新日志显示 Canvas 已于 10 月 31 日（2.0.82）向所有人开放，「Batch visualize」可一次渲染场景里所有镜头。

案例。 第三方Prime Video 创意总监 Heather Cooper 用 2.0 做了系列构想《The Rider》的动作预告，视频结尾附了幕后流程：先把角色、房子、摩托和汽车参考放到一块板上，再进入场景与镜头。

同日视频工具动态。 官方Seedance 2.5 4K 在 Pika 与 Runway 上线，Pika 明确标「原生 4K」，可先出草稿再定稿 4K；Luma 上线 Character Swap & Insert，同一镜头里换演员、换车、加一只狗或删掉一个人。

局限。 复杂动作与表演仍取决于底层视频模型；3D 场景的搭建质量依赖 agent 生成的资产，官方未给出量化评测。

是否值得读原文 · 做 AI 短剧 / 预演管线的值得看帮助文档首页「What is Intangible?」和 Cooper 的幕后片段，这是「3D 白膜 + 相机 + 生成渲染」思路的完整产品化样本。

第 06 节

高效使用 AI / Agent

两条实用结论：同预算下换更大模型比把推理力度拉满更划算；红队测试别只给「夺旗」任务

2026-11-12 · Perplexity · 2026-11-11 · 原文 AA 帖 1 分钟；Perplexity 博客约 15 分钟

选模型。 第三方Artificial Analysis 按单任务成本画 Claude 全系的性能—成本曲线，结论是：在几乎每个成本档位上，帕累托前沿上的都是更大的模型（Opus 5.5）。也就是说，与其让小模型开到最高推理力度，不如换上一级模型、用较低力度。这只针对当前 Claude 产品线。

红队方法。 官方Perplexity 用 12 个模型攻击自家 Computer agent 的虚拟机沙箱 SPACE：一个任务是逃出虚拟机读取宿主机上的凭据，一个是绕过网络策略访问被封的 URL。新增测试的 Claude Mythos 5.1、Claude Opus 5.5、GPT-6 Astra 也都没逃出虚拟机。关键发现是：标准的「夺旗（CTF）」任务写法会让 agent 花大量精力去找藏起来的 flag，而不是去测真正要评估的隔离边界；把任务改写成明确指向「宿主—客体隔离」后，agent 的努力随之转向目标。另一个发现是专门做网络安全训练的 GPT-5.6 Cyber 在这里反而不如通用的 GPT-5.6 Sol。第三方Part I 曾披露，十个第三方沙箱平台中有八个存在类似的网络绕过漏洞，已按负责任披露流程通知。

局限。 AA 的结论只有一张图和一句话，未公开各档位数据；Perplexity 的实验在自家沙箱上，结论外推到其他隔离方案要谨慎。

Gemini Decision 1：不生成文字、只给选项打分，一次最多 1,000 个问题，$0.10 / 百万输入 token，输出免费

Google DeepMind · 2026-11-11 · 原文 官方博客约 6 分钟

是什么。 官方「决策模型」专做封闭选项判断：工具选择、策略检查、模型路由、上下文打分。传入一份多模态共享输入（文本、图片、音频、视频、PDF，最长 256K token）加最多 1,000 个独立问题，模型一次前向给每个选项打分，返回概率和 0–1 的置信度。三种题型：是 / 否、2–255 个选项的单选、有序量表评分。

数字。 官方端到端延迟 150–250 毫秒，1 到 100 个问题几乎持平；在官方共用的测试集上比 Gemini 3.5 Flash-Lite 便宜近 5 倍。内部已用于 Gemini Notebook 的动态模型路由、搜索里 MCP 的对抗行为检测等。第三方Artificial Analysis 决策指数 v2.1 得 66，知识与推理类领先；Simon Willison 指出 API 设计几乎照搬 TypeSafe 的 Jev（连「Noul」这个是 / 否题型名都沿用），价格与 OpenAI 的 GPT-6 Luna 决策模型相同，Jev 仍最便宜（每百万 4.2 美分），但 Gemini 是三者中唯一全模态的。

局限。 只做封闭选项，开放问题仍要 LLM；各问题并行打分、彼此看不到，需要链式推理的判断不适合。

短评。 评论agent 里大量「小分支」调用（要不要调工具、该路由到哪个模型、这段上下文相关吗）原本都在付生成 token 的钱，决策模型把它们变成便宜、可校准的分类；低置信度再交给大模型或人，是很自然的分层做法。

是否值得读原文 · 值得，做 agent 编排的读博客的三种题型和置信度用法。

产品与行业：Claude 上线 Sheets / Whiteboards / Data；Qwen4-Max 预览；Anthropic 定 11 月 19 日上市

Anthropic · 2026-11-10 · 阿里云 · Boston Business Journal · 原文 各约 3–6 分钟

Claude 办公三件套。 官方Whiteboards（beta）：口述一个零散计划，Claude 整理成带负责人和日期的时间线白板，团队实时协作，框选一块即可提问，可转成文档 / 幻灯片或导入 Lucid、Miro。Sheets（beta）：从一句提示生成带标签页、公式、格式和下拉框的表格，在单元格里编辑并标出每处改动。原 Claude Dashboards 正式更名 Claude Data，加入数据故事、认证查询和实时共享。所有付费计划可用。

Qwen4-Max 预览。 官方阿里通义发布下一代旗舰预览，面向复杂编码与专业任务，支持文本、图像、视频输入、工具调用、结构化输出和 100 万 token 上下文，兼容 OpenAI / Anthropic 接口，开放至 11 月 25 日。第三方多家媒体指出官方未公布基准、模型卡、参数量，也未开放权重；有实测反映生成偏慢。
