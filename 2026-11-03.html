OpenAI LifeVal：用用户调查锚定「日常助手」该帮什么，并内部追分

OpenAI · 2026-11-02 · 原文 约 6–8 分钟（官方页）

发生了什么。 官方OpenAI 发布内部评测 LifeVal，用来衡量模型在「真正想用个人助手」的日常任务上的进展。任务来源先对照美国 / 多国时间使用调查，再做一轮人口代表性调查（3,995 名受访者），覆盖照护、健康、教育、家务行政、个人财务、购物、政府服务等。官方强调：要成为真正有用的个人助手，ChatGPT 不能只给建议，还要能把事办完（浏览器 / 电脑使用、连接器等）。

页面上的任务样例分（官方）。 官方迁居后选幼儿园短名单 93.1%、洪水前组织志愿者 98.0%、按预算与接送约束找房并加购契到购物车 100%、远程陪奶奶看比赛 96.3%、糖尿病饮食周计划 90.4% 等。

总体分（第三方转引）。 第三方多家媒体（如 Quartz 转 CNN）报道：未加权平均奖励上，GPT-6 Astra 约 80% / 80.6%，对照 GPT-5.2 的 49.3%。官方产品页正文未给出同一套对照表，数字以第三方转述为主；评测目前属内部使用，未见公开排行榜或第三方复现包。

评论LifeVal 的价值不在又一个排行榜，而在把「用户真正想外包的日常责任」写成可追分的任务分布——和纯学术知识评测拉开距离。局限是：内部 rubric、未见开放题库，跨厂商对比要等第三方或官方开放。

是否值得读原文 · 官方页约 6 分钟扫任务样例即可；要总体分对照看第三方报道并保留转引心态。

第 02 节

RSI（自我迭代 / 人参与的迭代）

Weight-Space Programming：前沿模型直接读写神经网络权重（不用梯度）

Rikiya Takehi / Jayden Teoh / Alex Zhang / Omar Khattab（MIT CSAIL） · 2026-11-02 · 原文 约 25–40 分钟

问题。 过去 RSI / 自动优化管线多半是「模型写代码 → 启动训练作业」。作者问：前沿 LLM 能不能直接读、写、改权重本身——他们称之为 Weight-Space Programming。

怎么做的 / 证据。 官方用 GPT-6 Astra：

  • 读： 只看原始权重，能辨认策略网络在玩哪款游戏；能从去掉输入输出层的中间块判断小 LM 训在 Python / 罗马字日语 / 英语，并标出 copying / induction head，与实测一致。
  • 写（从小网络）： 零训练、零环境 rollout 写 MinAtar 权重，Breakout 得分压过训了 1 亿步的 PPO；在允许有限 forward pass 的 harness 下，可写出约 150 万参数级 9×9 围棋网络。
  • 改真实小 LM： 给 Qwen3.5-0.8B 配 Python kernel + 练习题 forward pass 预算（无梯度、无训练）。Astra 定位到层 15 / 19 MLP 里导致推理循环的方向，改掉约 131,072 个权重（全模型约 0.016%）。50 次 forward pass 预算下，MATH-500 7.9% → 48.1%，GSM8K 13.8% → 67.1%，IFEval 21.0% → 62.3%；撞 32k token 上限的比例 93.0% → 33.1%。

局限（作者自述）。 官方对几乎不循环、错误是「真不会算」的 Gemma 3 270M，同样预算几乎抬不动 MATH-500（约 6.8%→最高约 7.7%）。作者坦言：改权重能去掉挡能力的障碍，加不出模型本来没有的能力。规模仍远小于 frontier 自改；上下文与 harness 效率是瓶颈。完整日志与改后 Qwen 权重已公开，便于复现。

评论对 RSI 叙事这是质变候选：从「写训练脚本」扩到「原生编辑权重空间」。眼下更像「超强机解 + 局部故障切除」的火花，不是已验证的自改进闭环——但路径已经写清楚。

是否值得读原文 · 值得。先读 TL;DR 与 Experiment 8 表，约 15 分钟；要复现再开 GitHub 日志。

Deep Principle Hydrogen-1.0：面向化学 / 材料 / 生命科学的开源权重科学模型

Deep Principle · 2026-11-02 · 原文 约 15–20 分钟

发生了什么。 官方Deep Principle 发布 Hydrogen-1.0：在 GLM-5.3 上做科学向后训练，数据含化学 / 材料 / 生命科学领域知识、实验室记录，以及发现轨迹（含失败与修正）。权重开放（Hugging Face / ModelScope），另有 API（NeuroSpark）与自家 AI Scientist（Mira）。

关键数字。 官方/ 发帖FrontierScience-Research（FSR）上 38.3%，对照 GPT-6 Astra 33.3%；博文称在 GPQA Diamond 上相对 GLM-5.3 有提升，大致贴近开源前沿 Kimi-K3。内部场景：科学计算与一步前向反应预测上，相对 Astra 最高思考档约各高 5.13 / 4.76 个百分点；NMR 结构解析则 Astra 最高档仍高 3.33 点。材料发现轨迹评测中，五轮后 best-so-far HOMO–LUMO gap 均值：Hydrogen 4.318 eV vs Astra 3.689 vs Kimi-K3 3.353（同起点、各看各的反馈）。

训练思路。 官方SFT + RL；强调完整实验生命周期记录与可恢复 rollout。实验室编译（lab compilation）在虚拟环境里先查协议可行性再上真机。

评论「专用科学开源权重」比再发一个通用聊天榜更稀缺；FSR 小幅超 Astra 的数字要结合任务分布读，不等于全面科学超 frontier。对 Dong 做短剧 / Agent 管线的旁支启发是：领域轨迹（含失败）比只堆论文摘要更像可学的发现策略。

是否值得读原文 · 关心科学 Agent / 开源科学模型则值得，约 15 分钟；只看数字扫 Figure 1–3 即可。

Schmidhuber 要点。 官方重申 1990 世界模型图、人工好奇心与线性 Transformer 前史；强调屏幕后 AI（棋、证明）已强，Physical AI 仍无人独占；硬件进步远慢于算力，日本 / 德国机器人传统是机会。

评论把「世界模型当物理试前过滤器」写进公司主叙事，和 Dong 关心的白膜 / 预演管线同构：贵的是真机（或真渲染）试次，便宜的是潜空间里筛镜头与动作。Sawara 时间表偏远，近期价值在 RSI Lab 三团队拼图是否跑通闭环。
